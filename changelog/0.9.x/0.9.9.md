# 0.9.9 — 2026-08-22

## Added

- **`eurlex_get_document` pagination enrichment** — a capped body window now carries the returned character count, active cap, and exact next offset in both structured and text output; the final page omits the truncation notice.
- **Community health files** — contribution guidance and a code of conduct now route server, framework, conduct, and private security reports to the right place.

## Changed

- **`@cyanheads/mcp-ts-core` 0.12.3 adoption** — the server now supports protocol revision 2026-07-28 while retaining 2025-era clients, rejects undeclared tool-input keys, and advertises structured error envelopes that client validators can accept.
- **HTTP session mode** — `.env.example`, the container image, and the README now explicitly select stateless serving; `auto` remains documented as resolving to stateful.
- **Build and verification tooling** — TypeScript 7 typechecks both source and tests, the Docker image omits unused optional peer tiers, and project scripts plus agent skills match the current framework templates.
- **Security reporting** — private reports now use `security@caseyjhand.com`, with explicit redaction guidance for reproductions.
