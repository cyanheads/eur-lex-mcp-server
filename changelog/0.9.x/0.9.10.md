# 0.9.10 — 2026-08-30

## Changed

- **`eurlex_search_documents` document categories** ([#65](https://github.com/cyanheads/eur-lex-mcp-server/issues/65)) now expand each public `document_type` to the reviewed CELLAR authority family, so delegated, implementing, international, framework, proposal, and recommendation variants search under the same category instead of only one seed code.
- **Resource-type labels** ([#65](https://github.com/cyanheads/eur-lex-mcp-server/issues/65)) now cover the newly admitted document-family codes, so returned rows describe those variants with human-readable labels instead of raw authority identifiers.

## Fixed

- **`include_consolidated` category matching** ([#66](https://github.com/cyanheads/eur-lex-mcp-server/issues/66)) now qualifies a consolidated text only when `cdm:act_consolidated_based_on_resource_legal` reaches a basic act in the selected family, avoiding cross-category false positives and restoring valid consolidations that lacked the broader `consolidates` edge.
