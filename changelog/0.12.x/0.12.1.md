# 0.12.1 — 2026-09-16

## Changed

- **Session posture is now declared in source** — `createApp({ sessionMode: 'stateless' })` ([cyanheads/mcp-ts-core#376](https://github.com/cyanheads/mcp-ts-core/issues/376)). A source run with `MCP_SESSION_MODE` unset now serves stateless, where it previously resolved `auto` → stateful; the Docker image already pinned stateless, and `MCP_SESSION_MODE` still overrides both. Verified: `GET /mcp` reports `stateless` unset, `stateful` with `MCP_SESSION_MODE=stateful`.
- **`/.well-known/mcp.json`** publishes the resolved session mode under `_meta["io.github.cyanheads.mcp-ts-core/sessionMode"]` ([cyanheads/mcp-ts-core#387](https://github.com/cyanheads/mcp-ts-core/issues/387)). Verified on the local build.
- **An empty or whole-value unsubstituted `${…}` env var** now reads as unset and falls through to the `parseEnvConfig` schema default, rather than being treated as a literal value ([cyanheads/mcp-ts-core#427](https://github.com/cyanheads/mcp-ts-core/issues/427)).
- **`SIGTERM`/`SIGINT`** now exit the process explicitly once shutdown settles ([cyanheads/mcp-ts-core#435](https://github.com/cyanheads/mcp-ts-core/issues/435)).
- **The framework development skill tree moved from `skills/` to `framework-skills/`** ([cyanheads/mcp-ts-core#428](https://github.com/cyanheads/mcp-ts-core/issues/428)) — a plugin install no longer hands these skills to the installing agent; scripts, `.mcpbignore`, and doc links synced to match.
- **README restructured** around a per-primitive capability reference — Overview plus Tools/Resources/Prompts summary tables, then one section per tool, resource, and prompt.
- **Claude plugin manifest** (`.claude-plugin/plugin.json`) gains a `$schema` reference, author email/url, and the package keyword list.
- **GitHub issue templates and `CONTRIBUTING.md`** synced from the scaffold: scoped labels, auto-assign to `cyanheads`, blank issues allowed, a security-advisory contact link.
- **`.env.example`** documents why `MCP_SESSION_MODE=stateless` is set explicitly rather than left to the `auto` default.
