# 0.12.2 — 2026-09-20

## Added

- **Three resource-type labels** — `CONS_TEXT` → "Consolidated Text", `MEAS_NATION_IMPL` → "National Implementing Measure", `CORRIGENDUM` → "Corrigendum" — replace the raw authority code these common outputs previously surfaced as ([#86](https://github.com/cyanheads/eur-lex-mcp-server/issues/86)).

## Changed

- **CI reduced to one workflow**, `.github/workflows/codeql.yml` — GitHub-owned CodeQL only; verification stays local.
- **Framework skill tree and `scripts/lint-mcp.ts`** synced to mcp-ts-core 0.13.6, adding `thrownBy: 'service'` conformance metadata and a `devcheck.config.json` `lint.truncationAllowlist` knob.

## Fixed

- **`eurlex_get_document`'s entity decoder** now decodes each character reference exactly once instead of chaining sequential replaces, which re-decoded already-escaped markup (`&amp;lt;` → `&lt;` → a literal `<`); an out-of-range numeric reference is now left verbatim instead of throwing ([#79](https://github.com/cyanheads/eur-lex-mcp-server/issues/79), [#87](https://github.com/cyanheads/eur-lex-mcp-server/issues/87)).
- **`select` on `eurlex_get_document`** is now bounded to the same 100,000-character cap as `paged`/`full` bodies. A selection is a set of disjoint slices, not a contiguous window, so `has_more` no longer implies a resumable offset; `selected_sections` gives each matched section its own `offset`/`chars` for an individual re-read through `paged` ([#80](https://github.com/cyanheads/eur-lex-mcp-server/issues/80)).
- **`eurlex_search_documents`'s `in_force` filter** now applies for both polarities — `in_force: false` previously built no clause, silently returning the unfiltered set while still echoing itself as applied ([#82](https://github.com/cyanheads/eur-lex-mcp-server/issues/82)).
- **Corrigenda are now excluded from `eurlex_search_documents`'s default result set** — a correction work is co-typed into every `document_type` family and sorted primary acts off the page; `include_corrigenda` re-admits them, and every row is tagged `is_corrigendum` ([#83](https://github.com/cyanheads/eur-lex-mcp-server/issues/83)).
