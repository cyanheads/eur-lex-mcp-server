# 0.12.0 — 2026-09-09

## Changed

- **`eurlex_get_document`'s `legal_basis` and `eurovoc_subjects`** are now `{ work_uri, celex_number? }[]` and `{ concept_uri, label? }[]`, not bare URI strings — consumers must read `.work_uri`/`.concept_uri` instead of the array element directly. Resolved via `OPTIONAL` joins on the existing dimension queries; the `eurlex://document/{celexNumber}` resource gained both fields with the same shape (#67).
- **`eurlex_lookup_celex`'s `resource_type`** now returns the human-readable label (e.g. "Regulation") via the shared `resolveResourceTypeLabel`, falling back to the authority code when unmapped (#58).

## Fixed

- **`eurlex_query_sparql`'s `sparql_timeout`** error is no longer retried: a client-side `AbortSignal.timeout` abort and Virtuoso's `SP031` execution-limit error both fail immediately with a recovery hint, so a call ends inside its configured bound instead of retrying four times (#78).
