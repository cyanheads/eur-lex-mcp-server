# 0.16.1 — 2026-09-25

## Changed

- **Served bodies are cached in process** by CELEX, requested language, and format, for one hour and up to 16 million retained characters, so paging an act fetches it once and converts Markdown once; unavailable bodies and cancelled calls are not stored ([#127](https://github.com/cyanheads/eur-lex-mcp-server/issues/127), [#129](https://github.com/cyanheads/eur-lex-mcp-server/issues/129)).
- **Markdown converts block by block**, so a Markdown outline of `02013R0575-20240709` peaks near 640 MB instead of 1.6 GB. Output differs from 0.16.0 in line-end whitespace and blank-line runs, so Markdown offsets can shift ([#127](https://github.com/cyanheads/eur-lex-mcp-server/issues/127)).

## Fixed

- **`format: "xml"` for zip-only acts**: when `application/xml;type=fmx4` answers 404, the zipped Formex package (`application/zip;mtype=fmx4`) is fetched and its manifest and named parts assembled, in manifest order, into the same `<formex-multipart>` wrapper as the HTTP 300 path; an unreadable package is `multipart_incomplete` ([#108](https://github.com/cyanheads/eur-lex-mcp-server/issues/108)).
- **Unavailable-body note** in the text channel now names the `content_unavailability_reason`; only `no_representation` mentions the language ([#108](https://github.com/cyanheads/eur-lex-mcp-server/issues/108)).
- **html `outline` and `select` on legacy `text/html` acts** (e.g. `31995L0046`): a block tag now ends a line on the html path, offsets still index the body as served, and heading titles decode `&quot;` ([#126](https://github.com/cyanheads/eur-lex-mcp-server/issues/126)).
- **Chapter and section headings with an inline title in capitals** (`CHAPTER I GENERAL PROVISIONS`) are detected, the title becoming the heading's `title` ([#130](https://github.com/cyanheads/eur-lex-mcp-server/issues/130)).
- **Legacy Finnish and Swedish outlines**: recitals numbered `N)` and a number-first article keyword with a case ending (`34 artiklan`) are detected ([#131](https://github.com/cyanheads/eur-lex-mcp-server/issues/131)).
- **Markdown of legacy and consolidated acts**: the legacy page's legal-notice banner is stripped, and a consolidated text's point labels (`1\.`, `(a)`) join the text after them instead of standing on a line of their own ([#120](https://github.com/cyanheads/eur-lex-mcp-server/issues/120)).
