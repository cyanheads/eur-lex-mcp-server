# 0.19.1 — 2026-10-22

## Changed

- **`eurlex_get_cases`** includes `VIEW_AG` alongside `OPIN_AG` for `case_type: "ag_opinion"`, retaining the distinct `AG View` label. ([#165](https://github.com/cyanheads/eur-lex-mcp-server/issues/165))
- **`eurlex_get_document`** returns sparse national-measure gazette citations and separate publication/notification dates, including metadata-only calls; unavailable bodies guide retrieval from the named gazette. ([#164](https://github.com/cyanheads/eur-lex-mcp-server/issues/164))

## Fixed

- **`eurlex_get_relations`** budgets each complete serialized output surface at 64,000 UTF-8 bytes by reducing per-type/direction depth, preserving whole rows and titles with correct continuation. A depth-1 page remains whole even when oversized, with disclosure. ([#160](https://github.com/cyanheads/eur-lex-mcp-server/issues/160))
- **`eurlex_get_document`** discloses missing legacy source tables across cached and paged HTML/Markdown views and returns CELLAR-advertised PDF alternatives when discovery succeeds. ([#162](https://github.com/cyanheads/eur-lex-mcp-server/issues/162))
- **`eurlex_search_documents`** matches national-court author names as well as English authority labels, with and without date bounds. ([#163](https://github.com/cyanheads/eur-lex-mcp-server/issues/163))
