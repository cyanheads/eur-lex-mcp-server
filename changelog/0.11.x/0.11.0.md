# 0.11.0 — 2026-09-09

## Added

- **`national_transposition`** relation type on `eurlex_get_relations` and the `/relations` resource summary, returning member-state implementing measures matched to the source directive's act core (#56).
- **`has_more`/`next_offset`** on `eurlex_search_documents`, `eurlex_get_cases`, `eurlex_browse_subjects`, and `eurlex_get_relations`: each fetches one extra row to prove a further page exists instead of inferring it from a full page (#72).
- **`continuation`** object on the `eurlex://document/{celexNumber}/relations` resource, pointing at `eurlex_get_relations` when the summary cap truncates (#71).
- **`matched_label`** on `eurlex_browse_subjects`: matches `skos:altLabel` in addition to `skos:prefLabel`, surfacing which alternative term matched (#70).

## Changed

- **`eurlex_get_relations`** resolves the source CELEX from `work_uri` for `consolidated_version`/`national_transposition` matching; a work carrying several CELEX numbers stands the act-core constraints down instead of picking one arbitrarily (#73).
- CELEX-typed inputs (`eurlex_get_document`, `eurlex_get_relations`, `eurlex_lookup_celex`, and both `eurlex://document/{celexNumber}` resources) now trim, uppercase, and validate against a shared `CELEX_PATTERN` before any CELLAR round-trip (#69).

## Fixed

- **`eurlex_search_documents`** and **`eurlex_get_cases`** reject an impossible or inverted `date_from`/`date_to` with `invalid_date_range` instead of silently returning `no_results` (#77).
