# 0.15.0 — 2026-09-25

## Added

- **`base_act_celex`** on `eurlex_get_document` and `eurlex://document/{celexNumber}`: a consolidated text names its base act, read from `cdm:act_consolidated_based_on_resource_legal` ([#110](https://github.com/cyanheads/eur-lex-mcp-server/issues/110)).
- **`repealed_by`, `entry_into_force`, `end_of_validity`** on `eurlex_get_document` when `in_force` is false: the explicitly repealing acts, an entry into force still ahead, and an end of validity other than the open-ended `9999-12-31`, read by the existing core query ([#111](https://github.com/cyanheads/eur-lex-mcp-server/issues/111)).

## Changed

- **`is_superseded`** describes the text served, not the requested act. Breaking: it is present whenever the act has a consolidated version in effect and `false` on the newest one, so a `resolve: "current_consolidated"` response now reads `false` and a consolidated CELEX request now carries it ([#109](https://github.com/cyanheads/eur-lex-mcp-server/issues/109)).
- **Consolidated-text metadata** on `eurlex_get_document` and `eurlex://document`. Breaking: authors, `in_force`, EuroVoc subjects, and legal basis now come from the base act; title, date, type, and work stay the consolidation's own ([#110](https://github.com/cyanheads/eur-lex-mcp-server/issues/110)).
- **`eurlex_get_relations` `consolidated_version`** lists the works whose based-on link names the act. Breaking: some acts return more rows (`32000O0007` 1 → 11), and on the `work_uri` path `celex_number` is omitted when `consolidated_version` is the only relation type requested ([#109](https://github.com/cyanheads/eur-lex-mcp-server/issues/109)).
- **`eurlex_search_documents` `is_consolidated`** is true for any sector-0 CELEX. Breaking: consolidations outside the `0{act}-YYYYMMDD` shape now read `true` ([#109](https://github.com/cyanheads/eur-lex-mcp-server/issues/109)).

## Fixed

- **Consolidation lookup** in `eurlex_get_document` follows the based-on link and takes the latest consolidation date on or before today, so differently numbered consolidations (968 of 443 acts, e.g. `22006A0901(01)`) are found and a future-dated one is never current; a future-dated consolidated text gets a `notice` that it does not apply yet ([#109](https://github.com/cyanheads/eur-lex-mcp-server/issues/109)).
- **`resolve: "current_consolidated"`** on a consolidated CELEX serves its base act's newest consolidated version ([#109](https://github.com/cyanheads/eur-lex-mcp-server/issues/109)).
- **`work_uri` carrying several CELEX** in `eurlex_get_document` serves the lowest instead of an arbitrary one, with a `notice` naming the count ([#104](https://github.com/cyanheads/eur-lex-mcp-server/issues/104)).
- **`eurlex_search_documents` `in_force`** description: `false` covers repealed, expired, and not-yet-in-force acts ([#111](https://github.com/cyanheads/eur-lex-mcp-server/issues/111)).
