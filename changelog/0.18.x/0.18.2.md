# 0.18.2 — 2026-10-07

## Changed

- **Tool error results carry `data.requestId`**, and their text ends with `request <id>` (`cyanheads/mcp-ts-core` 0.13.10). The id matches the one on the server's log records for the call.
- **An integer sent for a string argument, or a JSON-stringified object sent for an object argument, is repaired before validation** instead of being rejected (`cyanheads/mcp-ts-core` 0.13.9). `eurlex_lookup_celex` with `identifier: 32016` reaches the handler as `"32016"`.
- **`@modelcontextprotocol/server` ^2.0.0 → ^2.2.0** through the framework. From SDK 2.1 (`cyanheads/mcp-ts-core` 0.13.9), a 2026-07-28 POST without `MCP-Protocol-Version` is refused with `400` / `-32020`, and a JSON-RPC batch of more than 100 messages is refused.
- **Tool definitions drop their `ctx.recoveryFor` forwards.** The framework fills each tool's declared recovery hint (`cyanheads/mcp-ts-core` 0.13.10), so callers see the same hints. `tests/tools/eurlex-get-document.cache.test.ts` and `tests/tools/eurlex-query-sparql.tool.test.ts` assert them through `runToolContract`.
- **Docker image installs production dependencies in a `deps` stage on the build platform** and cross-installs for the target architecture (`cyanheads/mcp-ts-core` 0.13.10); musl-only packages are pruned from the image (`cyanheads/mcp-ts-core` 0.13.11). The production stage runs no `bun install`, and `MCP_FORCE_CONSOLE_LOGGING` is no longer set in the image. New scripts: `scripts/install-otel.ts`, `scripts/prune-musl-packages.ts`.
- **`server.json` npm entries launch through `npx`** without the `run start:*` arguments, and the `streamable-http` entry sets `MCP_TRANSPORT_TYPE` to `http` (`cyanheads/mcp-ts-core` 0.13.11).
- **`.gitignore` and `.dockerignore` cover every `.env*` file** except `.env.example`, `.env.template`, and `.env.sample`; `.dockerignore` also excludes the MCP Registry token files. `.mcpbignore` excludes `docs/idea.md`, `logs/`, and `.cache/` from the bundle.
- **`.github/workflows/codeql.yml` runs one job per language** (`actions`, `javascript-typescript`), each uploading under its `/language:<language>` category.
- **Linear-time regression tests time thread CPU time** through `tests/helpers/cpu-time.ts` instead of wall-clock time, so they pass on a heavily loaded machine and still fail on an injected quadratic regression.
- **`.env.example` documents the framework's opt-in variables** `MCP_REQUEST_STATE_KEY` (`cyanheads/mcp-ts-core` 0.13.10), `LOG_TOOL_FAILURE_PAYLOADS`, `LOG_TOOL_FAILURE_PAYLOAD_MAX_BYTES`, and `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` (`cyanheads/mcp-ts-core` 0.13.8), and `LOG_LLM_INTERACTIONS`. The README configuration table lists `LOG_TOOL_FAILURE_PAYLOADS`.
- **Framework skills and maintenance scripts resynced** to `@cyanheads/mcp-ts-core` 0.13.13; `lint-packaging` gains Dockerfile and `server.json` launch-shape checks.
