# 0.20.1 — 2026-11-03

## Added

- **`eurlex_get_document` and `eurlex://document/{celexNumber}` report `procedures`**: each interinstitutional procedure of an act or proposal as `{ reference, status?, withdrawal_date?, adopted_acts? }`, with `status` `adopted`, `withdrawn`, `pending`, or `not_adopted`, so a withdrawn proposal reads differently from a pending one ([#180](https://github.com/cyanheads/eur-lex-mcp-server/issues/180)). The query reads three dossier links: `work_part_of_dossier`, `dossier_produces_resource_legal`, and `dossier_initiated_by_act_preparatory`.
- **`dates_of_effect[].provision`** names the clause that sets a date (`Article 113(a)`, `Annex II`), and a date from which only some provisions apply is typed `partial_application` ([#181](https://github.com/cyanheads/eur-lex-mcp-server/issues/181)).
- **`eurlex_get_cases` filters by `member_state`, `procedure_type`, `outcome`, and `subject`**, and each case row carries `countries`, `procedure_types`, `subjects`, and `procedure_languages` where CELLAR records them; `query_echo.subject_labels` lists the subjects a phrase matched, and `invalid_subject` rejects a phrase with no letter or digit ([#178](https://github.com/cyanheads/eur-lex-mcp-server/issues/178)). `eurlex_get_document` reports the same four fields for case law.
- **`eurlex_lookup_celex` resolves Commission document numbers** (`COM(2021) 206 final`, also `SEC`, `SWD`, `JOIN`) **and procedure references** (`2021/0106(COD)`, to the act that initiated the procedure) under `identifier_type: "auto"`; one that names several works returns `found: false` listing each CELEX ([#179](https://github.com/cyanheads/eur-lex-mcp-server/issues/179)).
- **`eurlex_lookup_celex` reads more OJ reference spellings**: `OJ No L 281`, spaced dates, `pp. 1-88`, `O.J. L 281`, `[1995] OJ L281/31`, and a comma-less act-by-act number; one trailing period on an OJ citation is dropped ([#172](https://github.com/cyanheads/eur-lex-mcp-server/issues/172)).
- **`eurlex_get_relations` returns `transposition_summary`** on a first page that traverses `national_transposition`: measures and newest date per member state, and `member_states_without_measures` ([#182](https://github.com/cyanheads/eur-lex-mcp-server/issues/182)).

## Changed

- **`eurlex_get_relations` `limit` defaults to 10, down from 100** (ceiling still 100), and it is the only page boundary: the 64,000-byte response budget is gone, so a call returns the rows requested and `next_offset` is `offset` plus the limit served ([#183](https://github.com/cyanheads/eur-lex-mcp-server/issues/183)).
- **`eurlex_get_relations` no longer returns `relations[].provisions_withheld`**; with the budget gone, no row's `provisions` are withheld ([#183](https://github.com/cyanheads/eur-lex-mcp-server/issues/183)).
- **`eurlex://document/{celexNumber}/relations`** continuation input is `{ celex_number, offset: 25 }`, continuing where the summary stopped ([#183](https://github.com/cyanheads/eur-lex-mcp-server/issues/183)).
- **`sparql_timeout` from a spent time budget or client timeout is `retryable: true`**; a Virtuoso cost refusal stays `false`. Each query still gets one attempt per call, and recovery hints no longer offer an input the call already used ([#177](https://github.com/cyanheads/eur-lex-mcp-server/issues/177)).
- **`eurlex_search_documents`**: an empty `eurovoc_concept` search with `document_type` `JUDG` or `OPIN_AG` points to `eurlex_get_cases` `subject` instead of advising to broaden the filters, since CELLAR indexes no Court of Justice or General Court ruling by EuroVoc ([#176](https://github.com/cyanheads/eur-lex-mcp-server/issues/176)).
- **`eurlex_get_document` and the `eurlex://document/{celexNumber}` resource run the citation facts as their own concurrent query** instead of aggregates in the core query; output is unchanged ([#173](https://github.com/cyanheads/eur-lex-mcp-server/issues/173)).

## Fixed

- **CELLAR's `1001-01-01` undated placeholder** is reported as absent instead of a real date: document `date`, `related_date`, and `national_measure` `publication_date` and `notification_date` ([#184](https://github.com/cyanheads/eur-lex-mcp-server/issues/184)).
