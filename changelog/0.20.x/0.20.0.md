# 0.20.0 — 2026-10-26

## Added

- **`eur-lex-guide` Agent Skill**, published from root `skills/`. The server lists it in `skills/list` and in `resources/list` as `skill://eur-lex-guide/SKILL.md`, with a `skill://{+path}` resource template for its files. It covers identifier chains (CELEX, ELI, ECLI, case number, Official Journal reference), conclusion gates (in force, repealed, no ruling on an article, final wording), and a CELLAR SPARQL and CDM reference for `eurlex_query_sparql` (`references/sparql-cdm.md`). It also ships in the npm package, the Docker image, the `.mcpb` bundle, and plugin installs.
- **Root `plugin.json` and `mcp.json`**: the Agent Plugins 1.0.0 manifest pair ([cyanheads/mcp-ts-core#426](https://github.com/cyanheads/mcp-ts-core/issues/426)).
- **`bun run test:coverage`** script (`@vitest/coverage-istanbul`).

## Changed

- **`mcp-ts-core` 0.13.17: the HTTP transport no longer retains each request's abort signal**, ending a ~71 KiB per-request heap leak present in 0.13.16, which this server ran ([cyanheads/mcp-ts-core#786](https://github.com/cyanheads/mcp-ts-core/issues/786)).
- **`mcp-ts-core` 0.13.17: MCP SDK `@modelcontextprotocol/server` 2.3.1 → 2.4.0**, transitive through the framework.
- **`mcp-ts-core` 0.13.18: `escapeMarkdownInline`** adds a backslash before the last `#` of a run that a space or tab precedes at a line end (`abc #` → `abc \#`), so all `content[]` text, error text included, keeps a trailing ` #` from closing a heading. It also writes leading and trailing whitespace other than space and tab as numeric references (`&#160;`); the text reads back unchanged under CommonMark ([cyanheads/mcp-ts-core#781](https://github.com/cyanheads/mcp-ts-core/issues/781)).
- **Heading values ending in `#` with no space before it** (`C#`) no longer gain a backslash. The framework escaper (0.13.18) now keeps a trailing ` #` from closing an ATX heading, so the server's own final-`#` guard in `escapeMarkdownHeading` was redundant; both forms read back as `C#`.
- **`.mcpbignore`** is a root-anchored set ([cyanheads/mcp-ts-core#508](https://github.com/cyanheads/mcp-ts-core/issues/508)), and the `.mcpb` no longer ships the framework's build-only files (`CLAUDE.md`, `AGENTS.md`, `changelog/`, `scripts/`, `templates/`, config bases; [cyanheads/mcp-ts-core#791](https://github.com/cyanheads/mcp-ts-core/issues/791)).
- **README Getting started** is reshaped: hosted and local install commands first, Docker and source builds under Running the server.
- **`bunfig.toml`** `minimumReleaseAge` 3 days → 1 day.
- Framework skills and scripts synced to 0.13.18.
