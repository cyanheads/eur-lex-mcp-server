# 0.20.2 — 2026-11-09

## Added

- **`eurlex_get_relations` `related_sectors`** keeps, in every requested type, only related works whose CELEX opens with a listed sector; a type it empties is listed in `empty_relation_types`, a first page names the requested types with none in those sectors in the `notice`, and a call that traversed every type and found no CDM relations says so ([#191](https://github.com/cyanheads/eur-lex-mcp-server/issues/191)). `member_states` without sector `7` and `article` without `6` fail as `member_states_not_applicable` and `article_not_applicable`.
- **`inputAliases` on all seven tools**: `celex`, `max_chars`, `query`, `citation`, `reference`, `celexNumber`, and `celex_number` resolve to each tool's identifier, `limit`, keyword, or `sparql_query` input ([#194](https://github.com/cyanheads/eur-lex-mcp-server/issues/194)).
- **`eurlex_get_document` `language` reads three-letter ISO 639-2 codes (`fra`, `fre`), and `select` takes a string (`"Article 4"`), a list in a field (`articles: ["1", "5"]`), or a singular or case-variant key (`article`, `Articles`)**; an unsupported `language` names the 24 codes, and `eurlex_browse_subjects` `language` reads three-letter codes too ([#195](https://github.com/cyanheads/eur-lex-mcp-server/issues/195)).
- **`eurlex_get_document`, `eurlex_get_relations`, and the `eurlex://document/{celexNumber}` and `eurlex://document/{celexNumber}/relations` resources name the held CELEX** when a CELEX misses by one numbering convention (a consolidated CELEX with no date or a date no version carries, a `(nn)` suffix missing or extra, a number not zero-padded to four digits): `not_found` carries it in the message and `data.held_celex`, and on `eurlex_get_document` `resolve: "current_consolidated"` serves the current consolidated version instead. `eurlex_lookup_celex` returns `found: false` with a `notice` naming it ([#196](https://github.com/cyanheads/eur-lex-mcp-server/issues/196)).
- **`eurlex_lookup_celex` names the acts a procedure produced** when the procedure has no initiating act ([#190](https://github.com/cyanheads/eur-lex-mcp-server/issues/190)).

## Changed

- **`resource_type` carries a label for all 206 resource types CELEX works carry**, and the dead `AG_OPI` and `REC_SOFT` entries are gone ([#192](https://github.com/cyanheads/eur-lex-mcp-server/issues/192)).
- **A lookup CELLAR leaves without a complete response for 20 s is re-sent once** inside the call's time budget; paged and raw queries keep one attempt ([#193](https://github.com/cyanheads/eur-lex-mcp-server/issues/193)).
- **`eur-lex-guide` skill 1.1 → 1.2**, covering the held-CELEX misses, the acts a procedure with no initiating act produced, no-date placeholders, and the amendment notice.
- **`@cyanheads/mcp-ts-core` 0.13.22**: an out-of-range numeric string reports its bound, HTTP error responses echo the JSON-RPC id, a failed resource read logs once, Bun ≥1.4.4 is required, and startup refuses Node <24 and a malformed `MCP_HTTP_ENDPOINT_PATH` or `MCP_PUBLIC_URL`.

## Fixed

- **`eurlex_get_cases` and `eurlex_search_documents` hints name only filters the call can still change**: the `sparql_timeout` and `offset_past_window` recoveries offer only the narrowing filters the call left unset, the empty first-page notice offers broadening steps only on the filters it set, and `eurlex_search_documents` no longer suggests removing its only filter, which fails `no_filters` ([#186](https://github.com/cyanheads/eur-lex-mcp-server/issues/186)).
- **CELLAR's no-date values `1001-01-01` and `1002-02-02`** are left out of `dates_of_effect`, `transposition_deadlines`, and `end_of_validity`, so `entry_into_force` is the earliest real date ([#187](https://github.com/cyanheads/eur-lex-mcp-server/issues/187)).
- **`eurlex_get_document` `notice` names an amending act that changed an article setting a listed date of effect**, since CELLAR's dates can lag one, and points to the current consolidated version or the amending act to confirm the date; `dates_of_effect` itself is unchanged. An amended location counts when it is the article alone or continues with a space or a dot (`AR 113 PA 3`, `AR 123.3`), and a legislative read sends one query more ([#188](https://github.com/cyanheads/eur-lex-mcp-server/issues/188)).
- **`eurlex_get_relations` `content[]` names the `member_states` filter as the scope of its member-states-without-measures line** in place of "the default 27"; `structuredContent` is unchanged ([#189](https://github.com/cyanheads/eur-lex-mcp-server/issues/189)).
